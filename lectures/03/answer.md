## 宿題

- 取り組んだレベル：発展（b）
- やったこと：CodespacesでPiを動かし（モデルは`gemini-3.5-flash-lite`）、「`app/agent.py`が何をしているか説明して」と頼んだ。`/export`で書き出したセッションから、Piが実際にモデルへ送ったシステムプロンプトを取り出し、自分の`INSTRUCTIONS`と比べた。
- 結果：

| 種類 | Pi | 自分の`INSTRUCTIONS` |
|---|---|---|
| 役割 | ハーネスpiの中で動くコーディングアシスタント。ファイルを調べる・コマンドを実行する・コードを書き換えるのを手伝う | AIE2026の学習支援エージェント |
| ツールの使い方 | ファイル操作にはbash。見るときはread（catやsedではなく）。部分的な書き換えはedit、同じファイルの変更は1回にまとめる。editの置き換え元は正確に1か所に当たるものにする。writeは新規か丸ごと書き直しだけ。環境変数`PI_*`で状態を確かめられる | 用語や講座に固有のことは、答える前に必ず`search_glossary`。回の内容は`get_lecture_summary` |
| 答え方 | 簡潔に。ファイルのパスをはっきり示す | 最後に関係する回（第N回）を示す |
| 正直さ・分からないとき | 無し | 用語集に無いことは、推測で断定せず「用語集にはない」と伝える |
| あえてしないこと・安全 | 無し | 宿題の答えそのものは書かず、ヒントで導く |
| 作業環境の情報 | 今いる場所（cwd）。Pi自身のドキュメントの場所と、いつ読むか | 無し |
| 書き方 | 英語。`<tools>`・`<rules>`などのタグで節を区切る | 日本語。箇条書きだけ |

- 気づき・疑問：Piは独自の環境変数（`PI_*`）を持っている。答え方に「簡潔に」とは書くが、わからないときに「わからない」と答えるようなルールが設定されていない。
